Latest project

ThoughtLoom.

Clarity for the decisions that keep you up at night. An AI companion that asks the right questions, does the research, and gives you a perspective you can actually act on.

01

Adaptive questioning

Generates each next question from your previous answer - usually three to six, hard-capped at eight - and stores them so retries never lose your place.

02

Researched recommendation

Decides whether your question needs current facts, searches the web when it does, then commits to a clear position instead of hedging.

03

Memory that learns

Merges what it learns into global and per-category memory and recalls your most relevant past chats - while new users never get invented history.

Architecture

Flutter app Supabase · Postgres + RLS FastAPI service Cohere LLM + web search Persistent user memory

Token-verified ownership on every call · model and search behind swappable interfaces · pytest with fake model & fake Supabase.
